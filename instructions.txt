# Protein Function Classification

Machine Learning · Bioinformatics · Python · PyTorch

Исследовательский вопрос: можно ли определить семейство белка по его аминокислотной последовательности, и насколько нейросеть лучше простого ML-бейзлайна?

Например, белок представлен строкой символов:

```
MKWVTFISLLFLFSSAYS...
```

Каждый символ обозначает аминокислоту. Модель получает последовательность и предсказывает её класс — например, одно из нескольких заранее выбранных семейств белков.

Важно: принадлежность к семейству — не то же самое, что полная биологическая функция. Это будет классификация по выбранным меткам, а не доказательство того, что белок выполняет определённую функцию.

## 1. Данные: используем DeepLoc

Для проекта предлагаю датасет DeepLoc 2.0 — белковые последовательности с аннотациями субклеточной локализации. Задача состоит в том, чтобы предсказать, где в клетке находится белок: например, в ядре, цитоплазме, митохондриях или на мембране. Официальный набор включает десять категорий локализации и допускает несколько меток для одного белка.&#x20;

Почему это хороший вариант для портфолио:

- задача имеет понятный биологический смысл;
- датасет достаточно небольшой, чтобы начать без дорогого GPU;
- можно сравнить обычный ML с нейросетевым подходом;
- результаты можно оценивать отдельно по каждой категории, а не только по общей accuracy.

Обрати внимание: это многометочная классификация (multilabel classification), а не обычная multiclass-классификация. У одного белка могут быть несколько локализаций одновременно. Поэтому нельзя просто использовать обычную accuracy и считать задачу решённой.

Почему именно эти две модели:

- Baseline: TF-IDF с символьными n-граммами преобразует локальные фрагменты последовательностей в признаки, а логистическая регрессия предсказывает метки. Это быстрый и интерпретируемый отправной пункт.&#x20;

  [image](https://www.google.com/s2/favicons?domain=https://sklearn.org\&sz=32)

- 1D CNN: учится самостоятельно находить характерные локальные паттерны в аминокислотной последовательности. Она сложнее, но не обязана превосходить baseline — именно это и предстоит проверить.

Позже можно добавить третью модель — классификатор на эмбеддингах предобученной белковой языковой модели ESM-2. Это уже будет хорошим продолжением проекта, но сначала лучше получить воспроизводимый результат на двух моделях.

## 4. Как запустить на Arch Linux

После распаковки архива открой терминал в папке проекта:

```
python3.11 -m venv .venv
source .venv/bin/activate

python -m pip install --upgrade pip
pip install -r requirements.txt

python src/train.py
```

Первый запуск скачает данные. Обе модели будут обучаться на CPU, если CUDA недоступна. CNN может обучаться заметно дольше baseline.

После завершения появится папка `artifacts/` с метриками в `metrics.json` и сохранёнными моделями.

Если у тебя нет команды `python3.11`, используй существующее окружение Python 3.11 или создай его через `pyenv`. Для этого проекта я бы не использовал Python 3.14 без проверки совместимости библиотек.

## 5. Как довести проект до уровня портфолио

Не останавливайся на запуске скрипта. Сделай четыре вещи:

1. Исследовательский анализ: распределение длины последовательностей, частоты меток, дисбаланс классов и пропуски.
2. Сравнение моделей: сведи micro F1, macro F1 и macro average precision в одну таблицу. Объясни, почему результаты отличаются.
3. Анализ ошибок: найди локализации, которые модели предсказывают хуже всего, и проверь, связано ли это с редкими метками.
4. Научная честность: отдельно укажи, что случайное разделение похожих белков может завышать качество. Для более серьёзного эксперимента нужно разделять выборки с учётом сходства последовательностей.

Следующий логичный этап — добавить ESM-2, предобученную белковую языковую модель, и сравнить её эмбеддинги с TF-IDF и CNN. Это приблизит проект к задачам вычислительной биологии, но потребует дополнительных вычислительных ресурсов и загрузки весов модели.

Именно такой проект уже можно обсуждать на собеседовании: не просто «обучил нейросеть», а сформулировал биологическую задачу, построил baseline, сравнил подходы и разобрал ограничения эксперимента.
